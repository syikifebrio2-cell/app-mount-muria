# Muria Trail Planner

Desain aplikasi mobile bertema pendakian gunung bernama "Muria Trail" — aplikasi pemesanan tiket & registrasi pendakian Gunung Muria, Jepara. Gaya visual: outdoor/adventure, natural, modern, dengan palet warna hijau tua, cokelat tanah, dan aksen oranye sunrise. Gunakan foto/ilustrasi pegunungan berkabut dan tekstur alam sebagai latar hero section.

Buat wireframe/high-fidelity untuk layar-layar berikut:

Splash Screen — logo "Muria Trail" dengan siluet gunung.

Onboarding (3 slide) — perkenalan fitur: pesan tiket online, registrasi pendaki, info jalur & cuaca.

Login/Register — dengan opsi nomor HP, email, atau akun Google.

Home Screen — banner info Gunung Muria, cuaca real-time, kuota pendaki harian, tombol "Pesan Tiket Sekarang", menu jalur pendakian (Colo, Rahtawu, dll).

Halaman Pilih Jalur & Tanggal Pendakian — kalender ketersediaan kuota, pilihan basecamp.

Form Registrasi Pendaki — data diri (nama, NIK, no. darurat, golongan darah), jumlah anggota rombongan, upload KTP/surat sehat.

Ringkasan Pemesanan & Pembayaran — rincian harga tiket, asuransi, biaya parkir, metode pembayaran (e-wallet, transfer bank, QRIS).

E-Tiket / Bukti Registrasi — QR code tiket digital, detail rombongan, syarat & ketentuan pendakian.

Halaman Info Jalur — peta jalur, pos-pos pendakian, estimasi waktu tempuh, titik air, larangan.

Profil Pengguna — riwayat pendakian, sertifikat, notifikasi cuaca/darurat.

Sertakan bottom navigation bar dengan ikon: Home, Tiket Saya, Info Gunung, Profil. Gunakan font yang mudah dibaca (contoh: Poppins/Inter), rounded card, dan ikon outline bergaya minimalis. Pastikan desain ramah untuk pengguna yang mengakses dari lokasi dengan sinyal lemah (area pegunungan), dengan indikator loading dan mode offline untuk e-tiket.
